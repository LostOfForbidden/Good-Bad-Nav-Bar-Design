# WRA 410 — Assignment 01: Navigation Bar HTML & CSS

## Contents
- `good.html` links to `good.css` and presents a readable and very simplistic navigation bar design.
- `bad.html` links to `bad.css`; this file uses incredibly terrible, vibrant, hard-to-look-at colors that hurt my eyes when I made it. (EPILEPSY WARNING) Please open with caution.

Both pages contain a `<nav>`, a four-item unordered list, links with `href="#"`, and a `.current` link. The menus stack vertically through 769px and are horizontal starting at 770px.

## Process and disclosure
I used my laptop and some YouTube tutorials of basic CSS and HTML because I needed to brush up on a couple of skills. All this was coded in Visual Studio and on a live server. It had taken about 6 hours despite being a simple design. The reasoning for the delay is because of my tendency to procrastinate.

## Preview
Open `good.html` and `bad.html` in a browser. Resize the window to compare the layouts at 769px and 770px. The `#` links are placeholders required by the assignment and do not lead to separate pages.
